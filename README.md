# Ișę - Nigeria's Most Trusted Task Marketplace 🇳🇬

> Building trust in Nigeria's gig economy through physical verification

## 🎯 Our Mission

To create Nigeria's most trusted marketplace for everyday tasks by combining technology with physical verification. Every job is verified by real people before going live - eliminating fraud and building trust.

## 🔧 What We're Building

**Ișę** connects customers who need tasks done with verified taskers who can do them. Unlike other platforms, we physically verify every job posting through our agent network before it goes live.

### Key Features
- 🏠 Physical job verification by local agents
- 🔒 Multi-layer fraud prevention system
- 💰 Fair 20% commission (split between both parties)
- ⭐ Two-way rating and review system
- 🛡️ Escrow payment protection
- 📱 Mobile-first PWA

## 🛠️ Our Tech Stack

- **Frontend:** React, TypeScript, Vite, TailwindCSS
- **Backend:** Node.js, Express, TypeScript, Prisma
- **Database:** PostgreSQL
- **Cache:** Redis
- **Payments:** Paystack
- **Hosting:** Vercel (frontend), Railway (backend)

# Security Policy

## Reporting Security Vulnerabilities

**Please DO NOT report security vulnerabilities through public GitHub issues.**

Instead, please email security@getise.com with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes

## Response Timeline

- **24 hours:** Initial acknowledgment
- **7 days:** Preliminary assessment
- **30 days:** Fix deployed (for critical issues)

Thank you for helping keep Ișę secure! 🔒
