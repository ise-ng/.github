# .github

This repository holds **organization-wide defaults** for [Ișę](https://github.com/ise-ng) on GitHub.

- [`profile/README.md`](profile/README.md) — the public profile shown at [github.com/ise-ng](https://github.com/ise-ng)
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — how to report bugs, suggest ideas, and work with us
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — the standards we hold each other to
- [`SECURITY.md`](SECURITY.md) — how to report a security issue responsibly
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) — issue forms inherited by every repo
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) — the PR checklist inherited by every repo

Any repository in the org that doesn't define its own version of these files automatically falls back to the ones here. Edit them in one place; they apply everywhere.
