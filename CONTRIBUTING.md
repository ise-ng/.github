# Contributing to Ișę

Thanks for taking the time to be here. 👋

Ișę is a young product, and most of our code lives in private repositories while we build toward launch. That means we're not taking outside code contributions just yet — but there are still real, valuable ways to help, and we read everything that comes in.

## Ways to help right now

### 🐛 Report a bug
If something is broken or behaving strangely, tell us. A good report includes:

- What you were trying to do
- What you expected to happen
- What actually happened
- Steps to reproduce it
- Screenshots or a screen recording, if you have them
- Your device, OS, and browser

Open an issue using the **Bug report** template, or email [hello@getise.com](mailto:hello@getise.com).

### 💡 Suggest an idea
Spotted something that would make Ișę better for workers or customers? Open an issue with the **Feature request** template and tell us the problem you're trying to solve — not just the solution. The "why" helps us more than the "what."

### 🔒 Report a security issue
Please **don't** open a public issue for anything security-related. Follow our [Security Policy](SECURITY.md) instead.

## How we work internally

So you know what kind of team you'd be joining:

- **Conventional Commits** — `type(scope): description` (e.g. `feat(auth): add phone OTP resend`)
- **Trunk-based-ish flow** — short-lived branches, small PRs, reviewed before merge
- **Green before merge** — lint, type-check, and tests all run in CI on every PR
- **`main` is always shippable** — if it's merged, it works

## Want to do this for a living?

If you'd rather contribute full-time than from the sidelines, we'd love to hear from you: [careers@getise.com](mailto:careers@getise.com).

## Code of Conduct

Every interaction here — issues, discussions, email — is covered by our [Code of Conduct](CODE_OF_CONDUCT.md). Be kind.
